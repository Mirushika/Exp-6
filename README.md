# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM

# AIM:

To design a UML Diagram for the Exam Registration System which shows how students register for exams, staff process their registration, and the system generates hall tickets after payment.  

# SRS (Procedure):

1.Student starts the exam registration process.

2.Staff receives the registration request from the student.

3.Staff sends student details for verification to the examiner.

4.Examiner verifies the student profile and eligibility.

5.System displays the available exams after verification.

7.Student selects the desired exam from the list.

8.Staff fills and submits the exam registration form.

9.Student pays the exam fees through the staff.

10.System confirms the payment and updates the record.

11.System generates the hall ticket for the student.
